# Incident write-ups

One file per incident, dated. Fixed shape:

1. **Status:** resolved / mitigated / open
2. **Summary:** two or three sentences
3. **Timeline:** timestamped, from real logs
4. **What was ruled out,** and how
5. **Root cause**
6. **Impact:** who, what, how long
7. **Resolution**
8. **Follow-ups,** each with an owner
